# Claude 음성 모드에서 herdr 지시 보내기마다 허용 창이 뜨는 이유 (2026-11-26)
## 결론
- 1순위: 음성 모드가 커스텀 커넥터의 '쓰기' 도구(prompt_agent)에 대해 '항상 허용' 설정을 무시하고 '한 번만 허용'만 띄우는 현상. 2026-11-10 GitHub 이슈 anthropics/claude-ai-mcp #1245로 보고됐고 아직 미해결. 읽기는 그냥 되고 지시 보내기만 매번 묻는 증상과 같음.
- 2순위: 서버가 prompt_agent에 `_meta["anthropic/requiresUserInteraction"]: true`를 보내면 앱이 '항상 허용' 버튼을 숨김.
- 그 밖: 설정이 '항상 허용'이 아니라 '항상 확인', 커넥터 중복, 저장 설정 초기화 버그, 조직 정책.
## 확인 순서
1. 허용 창의 '세부 정보 보기'에서 어떤 도구인지 확인
2. 웹이나 데스크톱의 커넥터 > herdr > 권한에서 prompt_agent가 정확히 '항상 허용'인지, herdr가 두 개 이상 있지 않은지 확인
3. 서버 폴더에서 `grep -rn requiresUserInteraction .` 실행. 있으면 지우고 서버 재시작, 커넥터 메뉴에서 '도구 목록 새로고침'
4. 같은 폰에서 음성 말고 텍스트 채팅으로 같은 지시를 해 보기. 텍스트는 바로 되고 음성만 묻는다면 지금은 설정으로 고칠 수 없음(Anthropic 수정 필요). 우회책은 키보드 받아쓰기+텍스트 채팅
## 주의
- 지시 보내기를 항상 허용하면 확인 없이 터미널에 명령이 감. 커넥터 주소는 비밀번호처럼 다루기.
